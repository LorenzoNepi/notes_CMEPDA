Before starting, two questions need to be answered: \textbf{why do Neural Networks need to be deep? And what exactly is depth?} You can easily think of depth as the number of layers that are stacked on top of each other in a NN: the more layers, the deeper it is. The point is (as we will see in our examples) that if one NN is deeper than another with the same number of trainable parameters, it will be faster to train and will have better metric values. For really complicated and professional algorithms, the difference in efficiency is more than relevant.
